
# Curadoria Raiz

Projeto em Next.js + Tailwind CSS pronto para deploy na Vercel.

## Instalação

```bash
npm install
npm run dev
```

## Estrutura

- app/layout.jsx
- app/page.jsx
- app/globals.css
- public/images/

## Imagens necessárias

Coloque na pasta `public/images`:

- apagao-editorial.webp
- apagao-packshot.webp
- produtor-faccin.webp
- pao-sourdough.webp
- antepasto.webp

## Deploy

Suba no GitHub e conecte na Vercel.
